# Distribution & Community Launch

## Install

```bash
npx skills add Longfellow1/Principled-Simplicity-skill --skill deep-fix
```

## Discovery channels

| Channel | Route | Status / prerequisite |
| --- | --- | --- |
| skills.sh | Organic discovery via legitimate installs using Skills CLI | Check index after real installation; do not generate artificial installs |
| Awesome Claude Skills (ComposioHQ) | Fork + PR, following CONTRIBUTING.md | Needs a tested real-world example and platform compatibility evidence |
| Awesome Agent Skills (VoltAgent) | Fork + PR, following CONTRIBUTING.md | Wait until organic community adoption is demonstrable |
| ClawHub | Separate publication and license review | Do not publish before verifying current license terms against Apache-2.0 |
| AgentSkill.sh | Use the marketplace's current submission UI | Verify exact account and indexing requirements before submitting |

## Evidence to prepare

- One before/after example with input, skill output, and evaluation criteria.
- Installation smoke test with CLI version, agent target, and pass/fail result.
- Verified supported agent environments; avoid unsupported compatibility badges.
- Relevant GitHub issues, contributions, and real-user adoption rather than fabricated usage.

## Publishing checklist

- [ ] `SKILL.md` metadata and reference paths validated by CI.
- [ ] Install documented and smoke-tested.
- [ ] README screenshots and short demo GIF/video (optional).
- [ ] Marketplace submission complies with destination rules and license.
- [ ] Track organic installs, stars, inbound issues, and conversion sources monthly.
